Deconstructing Attention: From Vanilla Self-Attention to FlashAttention-2

Standard self-attention scales quadratically in memory IO because the intermediate attention matrix $\mathbf{S} = \mathbf{Q}\mathbf{K}^T$ requires materialization in high-latency High Bandwidth Memory (HBM). How does FlashAttention tile online softmax to achieve $O(N)$ memory and near-optimal FLOP utilization?

$$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}}\right)\mathbf{V}$$

The Mechanics of Autoregressive Decoding: KV-Cache & Rotary Positional Embeddings

During autoregressive generation, computing keys and values from scratch every token step turns $O(T)$ computation into $O(T^2)$. We review the exact memory formula for KV caching and why RoPE (Rotary Position Embeddings) elegantly encodes relative token distances.
